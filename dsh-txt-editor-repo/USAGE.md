# 使用说明

适用版本：dsh-txt-editor 2.4.4 · DSH 0.2.1 及以上（Web 版 / 桌面版）

---

## 一句话

**右侧栏里打开的 `.txt`，那个标签本身就是编辑器，左侧带行号。** 点进去打字，`Ctrl+S`，磁盘上的文件就更新了。

打开方式不变：对话里的成品文件卡片、右侧栏文件树、或对话正文里的文件链接都可以。

---

## 一、确认它生效了

1. 装好插件后**刷新页面**（`Ctrl+R` / `⌘R`）。
2. 打开任意 `.txt`。
3. 看右侧文档工具栏的**「查看器」下拉**：里面应该有一项叫 **可编辑文本**，并且是默认选中的。
4. 正文左边应该出现一列灰色行号。

> 如果打开的还是只读预览：点「查看器」下拉，手动选「可编辑文本」。切一次之后会记住。

---

## 二、界面

| 元素 | 含义 |
| --- | --- |
| **未保存** / **已保存 14:32** | 当前状态。打一个字就变「未保存」，存完显示时间 |
| **1,203 字 · 87 行** | 字数（不计空白）与行数，实时更新 |
| **重新载入** | 按磁盘重读，丢掉编辑框里的改动（有改动会先确认） |
| **保存** | 没改动时灰的；等价于 `Ctrl+S` |
| 左侧行号列 | 一个逻辑行一个号，跟着滚动走 |

正文铺满标签高度，中文按 14px / 1.9 行高排。

---

## 三、行号怎么读

- **一个自然段一个号**：按换行符编号。开了「换行」后，长段落折成多行显示，但**只占一个号**，落在第一行；续行不重复编号。
- **空行也有号**：段落之间的空行照样占一个号，引用「第 128 行」时不会数错。
- **编辑后自动跟上**：你把某行改长、让它折成两行，下面的号码会自动下移，不会错位。
- **关掉「换行」时**：一行一个号，长行横向滚动。
- 号码在分隔线左侧留 7px，不压线；两位数、三位数都完整显示。

## 四、三个动作

### 1. 改

直接在编辑框里打字。任何改动都会让状态变成「未保存」。

`Ctrl+S`（macOS `⌘S`）保存 —— **前提是光标在编辑框里**；焦点在别处时浏览器不会把这个快捷键送到编辑器。也可以点右上「保存」。

### 2. 存

存成功后状态变「已保存 时间」，版本号刷新，可以连续保存；磁盘上的文件立刻就是新内容。

### 3. 重来

「重新载入」放弃编辑框里的内容、按磁盘重读。有人在别处改了这个文件、你要接收新版本时用它。有未保存改动会先确认。

---

## 五、保存这件事，值得单独说

**整文件覆盖，不是增量。** 你在别处（VS Code、记事本）对同一文件的改动，只要没进编辑框，保存就会被覆盖。想保留两边：先「重新载入」，再改。

**有人抢先改了？它会拦住。** 每个文件有一个版本号。你打开后如果我（agent）或别的程序改过它，你点保存时保存不会执行，提示「文件已在磁盘上被改动，先重新载入再改」，而**编辑框里的内容一个字都没丢**。做法：先复制你的改动 → 重新载入 → 粘回去 → 再存。

**格式不会被打乱。** 换行（CRLF/LF）与原文件一致；BOM 有就保留、没有就不加；只支持 UTF-8（GBK 老文件请先转码）。

---

## 六、哪些文件编辑不了

| 情况 | 表现 |
| --- | --- |
| `.md` / `.markdown` | 仍是 Markdown 预览（只接管 `.txt` 与 `.text`） |
| 文件不在已登记工作区里 | 提示「这个文件不在已登记的工作区里」 |
| 「查看器」切到了别的实现 | 只读预览，切回「可编辑文本」即可 |
| DSH 低于 0.2.1 | 下拉里没有「可编辑文本」 |

## 七、常见问题

**保存按钮是灰的**
没有改动；或者焦点没进编辑框——点一下正文再试。

**按 `Ctrl+S` 没反应**
快捷键只在编辑框有焦点时生效；也可以直接点「保存」。

**行号看起来偏上/偏下一点点**
行号与正文共用同一个行框和字体基线，正常偏差在 1–2px 内。若明显错位，先刷新页面；仍有问题请截图反馈。

**行号里出现空隙 / 数字错行**
说明影子层的折行与正文不一致。2.4.1 起已把输入框的滚动条宽度计入，正常情况下两者逐行一致。

**保存成功，但对话里的文件卡片没变**
卡片是消息里的快照，不会跟着文件变；以编辑框和磁盘为准。

**同一个文件开了两个标签**
两个标签各有一个版本号，后存的那个会被拦住（409）。

---

## 八、限制一览

- 只接管 `.txt` / `.text`；
- 只能编辑已登记工作区内的文件；
- 只认 UTF-8；
- 没有自动保存、没有多标签同步；
- 路由前缀 `/novel-txt/*` 是全局的，同一个 DSH 不要装两份。
