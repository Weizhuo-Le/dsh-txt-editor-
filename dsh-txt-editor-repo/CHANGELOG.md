# 更新记录

右侧栏 `.txt` 编辑器：就地编辑、按段落编号的行号、版本守卫保存。

- 删掉上一代行号方案留下的死代码（两段被提前 `return` 掉的测量 effect、`LineGutter` 组件、镜像层与克隆相关的 ref 和 CSS），约 15KB、440 行不可达路径。**行为无变化**：行号仍由 2.4.0 的「影子层」直接排版。

### 修复
- 两位数被挤成两行：号码盒改为**固定宽度 41px + `white-space: pre`**，`10` / `100` / `200` 都完整显示。

## 2.4.2 — 2026-11-13

### 修复

## 2.4.1 — 2026-11-13

### 修复
- 影子层比输入框宽约 15px（输入框给滚动条留了宽度），导致「正文里折行、影子里不折」，该行以下的号码整体高一行。现在把滚动条宽度计入影子层的右内边距。

## 2.4.0 — 2026-11-13

### 变更
- **行号改为跟着正文流排版**：不再测量每行的 y 坐标，而是把一份正文副本放进影子层，让浏览器用同样的字体、行高、内边距、换行规则去排，号码就贴在那份副本的行里。编辑导致折行变化时，号码自动跟着走。
- 附带收益：打字时不再有任何测量动作，卡顿消失。

## 2.3.0 — 2026-11-08

### 变更
- 降低打字成本：镜像层与精确测量改为**停手后再跑**（220ms / 400ms），行号节点用 `React.memo` 隔离，样式表只渲染一次，布局重试加上限。

## 2.0.1 — 2026-11-02

### 修复
- **启用本插件后 DSH 无法启动**（web boot 崩溃）。根因：本模块只 inject `slots`/`locale`，会先于文档预览包激活，`ctx.slots.inject` 的回调处于 pending，被 `@deepseek-ai/dsh-client-ui-sidebar-documentpreview` 在其 `register()` 内部同步执行；回调里因注册表未就绪而回退去写自带的 `…/documentpreview/text` key，抛错被记成对方的激活失败，而任一 entry 激活失败就中止整个 web boot。
- 修法：`dsh.client.inject` 强制排在文档预览包之后；删除抢占自带 key 的回退；定义 / 槽位 / `apply` 全部 `try/catch`，保证本 entry 永不抛错。

## 2.0.0 — 2026-11-02

### 新增
- 右侧栏文档标签里的 `.txt` / `.text` 就地编辑（取代 1.x 的左侧整页文件浏览器）。
- 通过公开的 `documentPreviews` 扩展点注册 `extension` 档实现，Markdown / HTML / 图片 / PDF / Office 预览不受影响。
- 字数与行数、未保存标记、上次保存时间；`Ctrl+S` 保存。
- 版本守卫：保存走 `replaceIfVersion`，期间文件被改则返回 `409`，编辑框内容不丢。
- CRLF / LF 与 BOM 保留；只读写已登记工作区内的路径，请求需带 `x-novel-txt` 头并校验同源 `Origin`。
