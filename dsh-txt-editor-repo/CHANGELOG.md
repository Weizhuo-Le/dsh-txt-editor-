# 更新记录

本插件只做一件事：让右侧栏文档标签里的 `.txt` 变成可编辑。所有版本都遵循同一条设计约束——**激活失败不得拖垮 DSH 启动**。

## 2.2.1 — 2026-11-03

### 修复
- **双滚动条**：编辑框右侧同时出现输入框自己的滚动条和外层面板的一条。文档正文现在通过 `scrollportRef` 上报自己的滚动容器（宿主据此不再在外面套一层滚动），并把面板高度夹到外框实际可用高度；面板缩放时用 `ResizeObserver` 重新计算。
- 测量用的镜像层与精确测量克隆移入 0 尺寸裁切容器（`.rte-offscreen`），不再参与任何滚动区的溢出计算；`.rte-root` 增加 `overflow: hidden` 兜底。

## 2.2.0 — 2026-11-03

### 修复
- **行号与正文错位**（2.1.0 引入）。原因有三，全部修掉：
  1. 镜像层把 `white-space: pre-wrap` 写死在 CSS 里，而输入框受文档工具栏「换行」开关控制，关掉换行时两者断行完全不同；
  2. 测量失败时用「按行高等距」兜底，错位的号码因此铺满整屏；
  3. 缺少校验，镜像层与输入框断行不一致时仍照常发布坐标。
- 现在镜像层**复制输入框自己的排版属性**（`white-space`、`word-break`、`overflow-wrap`、`line-break`、`tab-size`、字距、字体、字重等 18 项），发布前用总高度校验，对不上就丢弃。

### 新增
- **精确测量**：一个同样带 `rte-text` 类名的隐藏 textarea 克隆，逐行增长读取 `scrollHeight`，得到输入框自己的断行结果，测完覆盖估算值。分片执行（每片 120 行），不阻塞输入。
- 行号补上 `padding-top` 偏移，与正文首行基线对齐。
- 量不准时行号栏留空，不再显示猜测的号码。

## 2.1.1 — 2026-11-03

### 修复
- 加固激活路径，消除一切仍可能抛错的入口：
  - 客户端 `apply()` 里的 `ctx.locale.bind()` 与两次 `ctx.effect(注册词典)` 移入独立 `try`（此前在保护范围之外）；
  - 宿主端三条路由注册收进 `mount()` 包裹，路由重复（例如装了两份）只丢路由，不影响宿主启动。

## 2.1.0 — 2026-11-03

### 新增
- **行号栏**：面板左侧常驻 48px 行号列，按逻辑行（`\n` 分隔）编号——开启自动换行时长段落仍只占一个号，号码对齐该段第一行；跟随滚动，滚动时只移动 `transform`，正文不重排。

## 2.0.1 — 2026-11-02

### 修复
- **启用本插件后 DSH 无法启动**（冷启动白屏 / 崩溃页）。根因是激活顺序：本模块只 `inject: ['slots','locale']`，会比文档预览包先激活，其 `ctx.slots.inject` 回调处于 pending，随后被 `@deepseek-ai/dsh-client-ui-sidebar-documentpreview` 在 `register()` 内部同步执行；回调里因 `documentPreviews` 尚未就绪而回退去写自带的 `…/documentpreview/text` key，抛错被记成**对方**的激活失败——而 web boot 只要有一个 entry 未激活就整体中止。
- 修法：`package.json` 声明 `dsh.client.inject: ["@deepseek-ai/dsh-client-ui-sidebar-documentpreview"]` 强制排在它之后激活；删除抢占自带 key 的回退；定义注册、槽位注册、整体 `apply()` 三层 `try/catch`，保证本 entry 永不抛错。

## 2.0.0 — 2026-11-02

### 新增
- 右侧栏文档标签里的 `.txt` / `.text` 直接就地编辑（取代 1.x 的左侧整页文件浏览器）。
- 通过公开的 `documentPreviews` 扩展点注册 `priority: "extension"` 的实现，Markdown、HTML、图片、PDF、Office 的预览完全不受影响；工具栏「查看器」下拉仍可切回自带的只读渲染。
- 字数 / 行数、未保存标记、上次保存时间；`Ctrl+S` 保存。
- 版本守卫：保存走 `replaceIfVersion`，期间文件被其他程序改动则返回 `409`，编辑框内容不丢。
- CRLF / LF 与 BOM 读取时识别、写回时还原。
- 只允许读写 DSH 已登记工作区内的路径，请求需带 `x-novel-txt` 头并校验同源 `Origin`。
