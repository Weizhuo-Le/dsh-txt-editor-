# dsh-txt-editor

[English](README.md) | 中文

**在 DSH 右侧栏里就地编辑 `.txt`** —— 你平时打开的那个文档标签直接变成可编辑文本框，左侧带**按段落编号的行号**，方便审稿定位。改完按 `Ctrl+S`，磁盘上的文件立刻更新。

完整操作手册见 **[USAGE.md](USAGE.md)**。

## 安装

```sh
dsh plugin --profile web add github:REPLACE_WITH_YOUR_USERNAME/dsh-txt-editor
```

桌面版：**设置 → 插件 → 从 GitHub 添加**。装完刷新页面（`Ctrl+R` / `⌘R`）。

> 没有发布到 npm，不影响安装：插件没有构建步骤，GitHub 源码就是完整的包。

## 它能做什么

- 把 `.txt` / `.text` 在文档标签里打开成**编辑器**，而不是只读预览；
- **左侧行号**：一个逻辑行（`\n`）一个号。长段落折成多行显示时只占一个号、落在第一行；空行照样有自己的号；**编辑导致折行变化时，号码跟着文字走**；
- 字数、行数、未保存标记、上次保存时间；
- `Ctrl+S`（macOS `⌘S`）保存；没改动时「保存」按钮是灰的；
- **重新载入**按磁盘重读，有未保存修改会先确认；
- 跟随文档工具栏的「换行」开关；
- 「查看器」下拉里叫 **可编辑文本**，随时能切回自带的只读渲染；
- **只有一条滚动条**。

Markdown、HTML、图片、PDF、Excel、Office 仍是原来的预览。

## 行号是怎么对上的

不用测量、不用算坐标：输入框背后放一层「影子」，里面是这份正文的一份副本，**字号、字体、行高、内边距、换行规则全部从真输入框身上读过来**；每个可见的号码就贴在那份副本对应行的左边。浏览器怎么排正文，就怎么排影子，所以号码不可能跑到别的行上去；你编辑把某行挤成两行，号码跟着下移。

两个关键细节：

1. 输入框**给滚动条留了宽度**，影子层要把这段宽度补进右内边距。否则影子比正文宽约 15px，某行「在输入框里折、在影子里不折」，下面所有号码就整体高一行。
2. 号码锚在**导航栏右边缘**（`margin-right`）而不是正文边缘，所以不会压在分隔线上。

滚动时整层影子用一个 `transform` 跟着走，不重排、不重绘正文。

## 工作原理

右侧栏的文档标签正文来自 DSH 的 `documentPreviews` 注册表，按**优先级档 + 文件后缀**挑实现。本插件注册 `extension` 档、后缀 `txt` / `text` 的实现——不改任何自带实现，也不顶替任何实现 id。

`dsh.client.inject` 把本模块排在 `@deepseek-ai/dsh-client-ui-sidebar-documentpreview` 之后激活。这不只是顺序问题：在它声明槽位之前注册，回调会跑在**它的** `register()` 内部，抛错会被记成它的激活失败，而只要有一个 entry 激活失败，整个 web boot 就中止。这里所有注册都做了异常保护，最坏情况是没有编辑器，绝不会让宿主起不来。

正文读写走插件自己的 Host 路由：

| 路由 | 作用 |
| --- | --- |
| `GET /novel-txt/list` | 已登记工作区里的 `.txt` / `.md` |
| `GET /novel-txt/read?absolute=1&path=…` | 正文 + 版本号 + 换行/BOM 标记 |
| `POST /novel-txt/save` | 写回 |

## 安全边界

- **只动工作区内**：每个路径都用 `fs.contains` 对着已登记工作区校验，之外的返回 `403`；写入显式带 `{ mode: 'workspace-write', workspaceRoot }`。
- **不会闷头覆盖**：读文件返回版本号，保存用 `replaceIfVersion`；期间被别处改过就返回 `409`，面板提示先重新载入，编辑框内容不丢。
- **不破坏格式**：CRLF / LF 与前导 BOM 读取时识别、写回时还原。
- **拒绝跨站写入**：请求必须带 `x-novel-txt` 头并校验同源 `Origin`。

## 兼容性

需要 DSH Web / 桌面版 **0.2.1 及以上**（这一线才带右侧栏文档预览包）。已在 `package.json` 的 `engines.dsh` 声明。

不 import 任何 `@deepseek-ai/*` 包：客户端只用文档化服务（`ctx.slots`、`ctx.locale`、`ctx.get('documentPreviews')`），Host 半只用 `ctx.fs`、`ctx.webServer`。无依赖、无安装脚本、无原生模块。

## 限制

- 只接管 `.txt`（以及 `.text`）；`.md` 仍是 Markdown 预览。
- 只有已登记工作区里的文件可编辑；只支持 UTF-8。
- 没有自动保存；撤销走浏览器输入框自带的撤销。
- 路由前缀 `/novel-txt/*` 是全局的——不要用不同包名装两份。
